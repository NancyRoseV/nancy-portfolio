AI Travel Platform

Intelligent Booking Ecosystem

A full-stack travel booking platform with AI-driven recommendations, dynamic pricing, and real-time availability across 200+ properties.

The Challenge

The client needed a booking platform that could compete with Booking.com and Airbnb but with AI-personalised recommendations. Users were dropping off during search due to overwhelming options.

My Approach

I designed a conversion-focused search flow with progressive disclosure — simple upfront, detailed filters on demand. Built the recommendation engine using user behaviour patterns and property metadata.

The Outcome

Search-to-booking conversion improved by 34%. The AI recommendation layer reduced time-to-book from 12 minutes to 4 minutes average.

Hospitality · 40+ Properties

Unified Multi-Site Booking Engine

A centralised search and booking system deployed across 40+ independent hotel websites, each with unique branding but shared core functionality.

The Challenge

Each hotel had its own WordPress site with inconsistent booking experiences. Maintenance was a nightmare — 40 separate codebases, 40 places for bugs. Guests expected a seamless experience.

My Approach

I architected a headless booking API with a white-label frontend system. Each site could customise colours, fonts, and imagery while sharing the same robust booking logic and database.

The Outcome

Reduced maintenance overhead by 70%. Booking completion rate increased 28% across the portfolio. New properties could launch in 2 days instead of 2 weeks.

Business CRM

Custom Workflow Automation CRM

A bespoke CRM system built from scratch to replace scattered spreadsheets and manual email follow-ups. Automated lead scoring, email workflows, and stakeholder reporting.

The Challenge

The client's sales team was losing leads in email threads. No visibility into pipeline health. Manual reporting took 6 hours every Monday. They needed a system that matched their workflow, not forced them into Salesforce.

My Approach

I ran stakeholder workshops to map their actual workflow — not the ideal one. Designed a dashboard-first interface where the most urgent actions surface automatically. Built automated email triggers based on lead behaviour.

Lead response time dropped from 8 hours to 45 minutes. Sales team saved 12 hours/week on admin. Management got real-time pipeline visibility for the first time.

Design System

Component Library & Design Tokens

A scalable design system created to unify the visual language across multiple client brands while allowing brand-specific theming.

The Challenge

Every new project started from scratch. Inconsistent buttons, spacing, and typography across 15+ client websites. Developers were rebuilding the same components repeatedly.

My Approach

I audited all existing interfaces to find patterns. Created a token-based system (colours, spacing, typography) with CSS custom properties. Built a component library with variants for each client's brand.

The Outcome

New project setup time reduced from 3 days to 4 hours. Design consistency score improved from 62% to 94%. Developers could focus on logic instead of styling.

Role Design System Lead
Tools Figma, CSS Custom Properties, Storybook
Coverage 15+ brands, 40+ components
Design Systems Component Libraries Design Tokens Figma CSS Architecture Accessibility
